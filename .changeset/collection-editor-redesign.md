The collection document editor is redesigned. Fields carry a label and a type hint and short fields share a row; list items are collapsible cards with a summary, a drag handle that works over its whole area, and a visible remove button; file and document pickers are labelled and list what is picked, with a link to each referenced document. The document page names its collection and full id, shows whether there are unsaved changes, saves with Ctrl/⌘+S, and asks before leaving with unsaved changes.
