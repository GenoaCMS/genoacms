The collection listing shows one line per document: the first text field leads each row, long values are cut short with their full text on hover, and each value is shown by its kind — a count for lists, a check mark for booleans, a short summary for objects, plain text for markdown — instead of `[object Object]` or wrapped text. A filter narrows the documents shown, ignoring case and diacritics, and Select all selects the documents shown.
