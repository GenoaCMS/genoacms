# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately in one of two ways:

- [Report a vulnerability](https://github.com/GenoaCMS/genoacms/security/advisories/new) through GitHub.
- Email [filip.holcik.official@gmail.com](mailto:filip.holcik.official@gmail.com) with the subject "GenoaCMS security".

Include the affected package and version, steps to reproduce, and what an attacker gains.

GenoaCMS is maintained by one person. Expect an acknowledgement within a few days, and a fix or a plan
for one as soon as the issue is understood. Please give a reasonable time to fix a problem before you
disclose it.

## Supported versions

GenoaCMS is under active development, and its packages are published at `0.x` (see
[Stability and versions](https://genoacms.js.org/guide/stability/)). Only the latest published release
of each package receives security fixes.

## Scope

In scope: the packages published under `@genoacms` on npm, and the code in this repository.

Out of scope: the sites that run GenoaCMS, and weaknesses in the cloud services an adapter talks to.
